# Social Network Intelligence and Graph Analytics System

## Project Overview
This project analyzes social network connections using graph analytics and machine learning techniques.

## Technologies Used
- Python
- Google Colab
- Pandas
- NumPy
- NetworkX
- Scikit-learn
- Plotly
- PyVis

## Project Modules
1. Dataset Collection
2. Data Cleaning and Preprocessing
3. Social Network Graph Construction
4. Network Statistics
5. Influential User Identification
6. Community Detection using Louvain Algorithm
7. Friend Recommendation System
8. Shortest Path Analysis
9. Link Prediction using Random Forest
10. Anomaly Detection using Isolation Forest
11. Interactive Network Visualization

## Dataset
Stanford SNAP Facebook Combined Dataset.

## Development Platform
Google Colab
